# 实机 Demo 视频 · 拍摄与剪辑脚本（v2，对齐白皮书 V1.0）

> 交付要求：MP4，3–5 分钟，必须包含在 CIX P1 开发板上的真实交互画面
> 目标成片：**3:50–4:20**，1920×1080 / 30 fps / H.264 / ≤ 500 MB
> 文件名：`Insight_Demo_CIX-P1_v1.0.mp4`

---

## 0. 先解决"怎么证明是实机在跑"

评审看的是"画面里的交互是不是板卡算出来的"。用**三层证据**同框：

| 层 | 画面 | 作用 |
|---|---|---|
| ① 交互层 | 浏览器全屏访问 `http://172.16.1.35:8848` / `:8849` | 真实交互 |
| ② 证据层 | 右侧 1/3 放一个 SSH 终端，实时刷 `ixsmi`、`/api/status`、`docker ps` | 证明算力在板卡上 |
| ③ 物理层 | 片头 5 秒板卡实拍（手机拍，带电源/网线） | 证明是一块真板子，不是云 |

> 没有第二块屏幕时：终端窗口和浏览器并排（浏览器 2/3 + 终端 1/3），不要切来切去。

## 1. 录制工具（按省事程度排序）

| 方案 | 操作 | 优点 | 缺点 |
|---|---|---|---|
| **Windows 自带 Game Bar** | `Win + Alt + R` 开始/停止；`Win + G` 打开面板 | 零安装，直接出 MP4 | 只能录单窗口/全屏，无场景切换 |
| **OBS Studio**（推荐） | 装好后建 3 个场景：浏览器全屏 / 分屏（浏览器+终端）/ 图片数据页 | 场景一键切、可加鼠标高亮、码率可控 | 需下载 ~150 MB |
| 剪映"录屏" | 剪映专业版 → 录屏 | 录完直接剪 | 帧率/码率选项少 |

- **剪辑**：剪映专业版（免费、中文、自动字幕）
- **转码/压缩**：板卡上有 `ffmpeg`（`/usr/bin/ffmpeg`），大文件可以 `scp` 到板卡压
- **本机没有 ffmpeg/OBS**——需先装 OBS，或用 Game Bar

## 2. 录前 10 分钟准备（不做会翻车）

```bash
# ① 清答案缓存：同图同题命中缓存只要 10–20 ms，录进去像假数据
docker exec -d qwen_opt bash /cix/rexseek-studio/start_agent.sh      # 约 76 s

# ② 等就绪
curl -s http://127.0.0.1:8848/api/status | python3 -m json.tool      # 四个服务全 true

# ③ 预热：用脚本外的问题问 2–3 次（首次 4–5 s 是 warmup，别录）
```

录屏设置：
- 浏览器 **1920×1080 全屏（F11）**，缩放 110% 让字更大
- 关闭微信/钉钉/系统通知；隐藏任务栏；桌面换成纯色
- 终端字号 16–18，标题栏保留 `cix@172.16.1.35`（这是"实机"的锚点）
- 鼠标移动放慢，点击前停 0.3 s（观众跟得上）

### 备用镜头（时长不够就加）

- 纯对话演示（`:8850`，59 ms 响应）——展示"无模型也能演流程"
- 多图轮流：webinar"讲者里有哪几位女性"、highway"找出那辆白色大巴"
- 功耗：`ixsmi` 在负载下从 21 W 跳到 40 W 的实时曲线

### 千万不要录

| 问法 | 实测问题 |
|---|---|
| 哪些番茄**还没熟** | 否定句不稳，答的还是"熟的 2 个" |
| **她是谁**（求婚图） | 退化成重新定位 |
| 最左边那颗番茄**熟了吗** | 回答含糊（"在画面中央"） |
| 讲者里有哪几位女性 | 输出"7 个women"，中英混杂 |

## 4. 录制执行顺序（一次过版）

1. **S1**：手机拍板卡 8 秒（上电、网线灯、风扇），后面用剪映加标题
2. **S7 先录**：趁服务刚起、终端输出干净，录 20 秒证据层（`ixsmi` 循环 + status + docker ps）
3. **S3/S4/S5**：按顺序录 8849 的三个示例，**每题只问一次**（重拍要重启 Agent 清缓存）
4. **S6**：录 8848 值守台（注意：台账已有历史事件，录前说明"历史沉淀"或只录新增那条）
5. **S9**：拔网线 → 问一句 → 插回
6. **S8/S2/S10**：静态页，最后在剪映里做

> 每段开头留 1 秒静止，段尾多录 1 秒，方便剪。
